## 更新日志

### **【一、插件功能总览】**

本插件为Ta提供了一个先进的多层记忆系统，使其能够记录、理解并回顾你们之间的互动。

#### **1. 五层记忆系统**

这是插件的核心，模拟了人类从短期记忆到长期设定的过程，确保角色行为的连贯性与深度。

| 层级 | 名称 | 作用与特性 |
|:---:|:---|:---|
| **0** | **锁定记忆** | **【世界观与恒定记忆】** 用于存放绝对不能忘记的核心设定，如身份、世界观、重要约定等。拥有最高优先级，**只能由用户通过命令/web网页手动管理**。 |
| **1** | **记忆日志** | **【日记】** 每30轮对话自动生成一次，以角色的口吻记录近期发生的事件，形成短期记忆。 |
| **2** | **核心记忆** | **【备忘录】** 与记忆日志同步生成，将信息整理为结构化的事实，方便AI快速查阅。 |
| **3** | **剧情框架** | **【故事大纲】** 每30轮对话追加更新，像大事记一样不断累积，记录了从开始到现在的完整故事脉络。 |
| **4** | **剧情总结** | **【剧情片段】** 每150轮对话生成一次，详细描述一个大章节内发生的具体剧情，是对故事大纲的细节补充。 |

#### **2. 高权重记忆注入** 🔥 新特性

本插件采用**直接注入到对话上下文（contexts）**的方式，而非传统的系统提示词（system_prompt）注入。

| 注入方式 | 注入位置 | 权重 | 说明 |
|:---|:---|:---|:---|
| 锁定记忆 | contexts | ⭐⭐⭐⭐⭐ | 作为伪对话注入，模型会严格遵守 |
| 核心记忆 | contexts | ⭐⭐⭐⭐⭐ | 作为伪对话注入，模型会牢记这些信息 |
| 剧情框架 | contexts | ⭐⭐⭐⭐⭐ | 作为伪对话注入，模型会记得故事脉络 |
| 对话历史 | contexts | ⭐⭐⭐⭐⭐ | 作为真实历史消息注入，完美保持连贯性 |
| 剧情总结 | system_prompt | ⭐⭐⭐ | 作为背景参考注入 |
| 近期记忆 | system_prompt | ⭐⭐⭐ | 作为背景参考注入 |
| 语义记忆 | system_prompt | ⭐⭐⭐ | 作为背景参考注入 |

**为什么权重更高？**
- LLM 会将 `contexts` 中的内容视为"真正发生过的对话"
- 而 `system_prompt` 中的内容更像是"可参考的背景说明"
- 通过伪对话形式（user问 + assistant确认），强化模型对设定的遵守

#### **3. 可替代 AstrBot 上下文** 🆕

开启"注入对话记录"功能后，插件会：
- 读取自己保存的完整对话记录
- 解析为标准的 user/assistant 消息格式
- 直接注入到 LLM 的 `contexts` 中

**优势：**
- ✅ **群聊互通**：共享空间内的所有会话共享对话历史
- ✅ **跨会话连贯**：私聊和群聊可以共用同一套对话记录
- ✅ **更长的记忆**：不受 AstrBot 本体上下文轮数限制
- ✅ **自动过滤命令**：OOC、系统命令等不会被记录

**使用方法：**
1. 在插件配置中开启 `inject_chat_history`
2. 设置 `chat_history_rounds`（建议 20-50 轮）
3. **将 AstrBot 本体的上下文轮数设为 1**（不能设为 0）

#### **4. 共享空间模式**

支持让同一角色在多个会话中共享记忆，适用于：
- 同一角色在多个群聊中使用，共享剧情进展
- 私聊和群聊共用同一套记忆
- 多人共同参与的长期剧情

| 数据类型 | 共享方式 |
|:---|:---|
| 记忆日志、剧情框架、剧情总结、对话记录 | **完全共享** - 所有加入此空间的会话共用同一份数据 |
| 核心记忆、锁定记忆 | **按用户隔离** - 每个用户拥有独立的核心记忆和锁定记忆 |

**使用流程：**
1. 使用 `/创建共享记忆 [空间名]` 创建一个新的共享空间
2. 使用 `/切换共享空间 [空间名]` 将当前会话加入该空间
3. 或者使用 `/迁移到共享模式 [空间名]` 将现有会话的记忆迁移并加入空间

#### **5. 语义记忆引擎**

插件能理解你当前对话的**含义**，并从海量的历史"记忆日志"中，搜索并注入语义最相关的记忆片段，实现记忆召回。

#### **6. Web管理界面**

插件内置了一个独立的Web管理界面，让你可以在浏览器中直观地管理所有记忆数据。

| 功能 | 说明 |
|:---|:---|
| **双模式切换** | 支持"会话模式"和"共享模式"两个Tab，分别管理独立会话和共享空间的记忆 |
| **仪表盘** | 查看存储空间占用、各类记忆条目数量等统计信息 |
| **记忆浏览** | 在线查看核心记忆、记忆日志、剧情框架、剧情总结、锁定记忆的完整内容 |
| **记忆迁移** | 将单条记忆（日志/总结/锁定）复制到其他会话或共享空间 |
| **历史版本** | 查看核心记忆的所有历史版本，每次更新都会自动备份 |
| **共享空间管理** | 创建新空间、迁移会话到空间、查看现有空间列表 |
| **快捷命令** | 一键执行记忆总结、剧情总结、重建向量等操作 |

#### **7. 完整文件管理**

你可以随时通过命令获取、更新或清空任何一层记忆的源文件，对角色的记忆拥有完全的控制权。

#### **8. 可靠性设计**

*   **备用服务商**：支持配置备用的AI服务商，在主服务商失败时自动切换，确保总结任务不中断。
*   **失败通知**：任何后台任务（如总结记忆）失败时，都会在对话窗口收到通知，方便你手动重试。
*   **超长文本保护**：当查看类命令的返回内容过长时，会自动提示你使用文件形式获取，避免消息被吞。
*   **核心记忆自动备份**：每次核心记忆更新时，旧版本会自动保存到历史目录，可在Web界面查看。
*   **剧情框架自动压缩**：当剧情框架超过指定字数（默认3000字）时，自动调用AI进行智能压缩，保留核心剧情脉络，防止框架无限膨胀。
*   **增量式总结**：记忆总结采用增量模式，只处理上次总结之后的新对话，避免重复总结历史内容。首次安装时自动跳过历史对话，从最新位置开始。

### **【三、共享空间详解】**

#### **什么是共享空间？**

共享空间允许同一个角色在多个不同的会话中共享记忆数据。例如：
- 你在私聊中和角色的对话
- 在群A中和角色的对话
- 在群B中和角色的对话

这些对话可以共享同一套剧情进展，角色在任何地方都能记得所有地方发生的事。

#### **数据隔离规则**

| 数据类型 | 存储方式 | 说明 |
|:---|:---|:---|
| 对话记录 | 共享 | 所有会话的对话都记录在同一个文件中 |
| 记忆日志 | 共享 | 基于共享的对话记录生成 |
| 剧情框架 | 共享 | 记录共同的故事主线 |
| 剧情总结 | 共享 | 记录共同的剧情片段 |
| **核心记忆** | **按用户隔离** | 每个用户有自己的备忘录 |
| **锁定记忆** | **按用户隔离** | 每个用户有自己的永久设定 |

#### **使用场景示例**

**场景1：多群共用角色**
```
1. 在任意会话中执行：/创建共享记忆 我的冒险
2. 在私聊中执行：/切换共享空间 我的冒险
3. 在群A中执行：/切换共享空间 我的冒险
4. 在群B中执行：/切换共享空间 我的冒险
```
现在这三个地方的对话都会共享记忆。

**场景2：迁移现有对话**
```
如果你已经在私聊中积累了大量对话：
1. 在私聊中执行：/迁移到共享模式 主线剧情
2. 在群聊中执行：/切换共享空间 主线剧情
```
原有的记忆会被迁移到共享空间，群聊也能访问这些记忆。

#### **注意事项**

- 每个会话同一时间只能加入一个共享空间
- 退出共享空间后，会话恢复为独立模式，但**不会复制**共享数据
- 迁移操作会**复制**数据到共享空间，原会话的独立数据仍然保留
- 建议在创建空间时使用有意义的名称，方便管理

### **【四、配置项说明】**

#### **对话历史注入设置** 🆕

| 配置项 | 默认值 | 说明 |
|:---|:---|:---|
| `inject_chat_history` | false | 是否将插件记录的完整对话历史注入到 contexts 中。开启后可替代 AstrBot 自带上下文，支持群聊互通。 |
| `chat_history_rounds` | 20 | 注入最近多少轮对话（1轮=1条用户消息+1条AI回复） |

> **⚠️ 重要提示**：开启 `inject_chat_history` 后，建议将 AstrBot 本体的上下文轮数设为 **1**（不能设为 0，否则会报错）。

#### **记忆注入设置**

| 配置项 | 默认值 | 说明 |
|:---|:---|:---|
| `injection_method` | system_prompt | 控制【记忆日志】和【剧情总结】的注入位置。核心记忆、锁定记忆、对话历史已默认注入到 contexts（权重最高）。 |
| `recent_diary_injection_count` | 5 | 每次固定注入的、最新的记忆日志数量 |
| `semantic_injection_count` | 3 | 根据当前对话语义搜索并注入的相关记忆数量 |
| `semantic_similarity_threshold` | 0.5 | 语义搜索相似度阈值（0-1之间） |
| `plot_summary_injection_count` | 5 | 每次注入的最近剧情总结数量 |

#### **共享模式设置**

| 配置项 | 默认值 | 说明 |
|:---|:---|:---|
| `memory_mode` | session | 默认记忆模式。session=按会话隔离，persona=按人格共享 |
| `persona_memory_inject_mode` | current_user | 共享模式下注入哪些用户的核心/锁定记忆 |
| `persona_whitelist_users` | "" | 白名单用户ID，多个用逗号分隔 |
| `persona_max_users_inject` | 5 | 最多注入多少个用户的记忆 |

#### **记忆总结触发设置**

| 配置项 | 默认值 | 说明 |
|:---|:---|:---|
| `summary_trigger_count` | 30 | 每多少轮对话触发一次记忆总结（一来一回算1轮） |
| `plot_summary_trigger_count` | 150 | 每多少轮对话触发一次剧情总结 |

#### **剧情框架自动压缩**

| 配置项 | 默认值 | 说明 |
|:---|:---|:---|
| `auto_compress_framework` | true | 是否启用剧情框架自动压缩 |
| `framework_compress_threshold` | 3000 | 剧情框架压缩阈值（字数） |

#### **Web管理界面配置**

| 配置项 | 默认值 | 说明 |
